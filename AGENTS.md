# Project rules

- Read `README.md` and `docs/development.md` before changing the project.
- Write project documentation in English.
- Run `just check` after changes.
- Preserve original media timestamps; never trim, retime or overwrite source recordings.
- Keep downloaded media, comments, credentials, caches and generated output out of Git.
- Treat comments as noisy reference labels, never as ground truth or detector inputs.
- Do not tune detection or recognition for exact agreement with comment timestamps.
- Keep local YouTube Studio exports usable without a network request.
